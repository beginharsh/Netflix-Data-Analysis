# Netflix-Data-Analysis

## 📌 Objective  
To analyze Netflix content library and identify patterns in movies & TV shows based on genre, release year, ratings, and country distribution. 

## 📊 Dataset  
- Source: Kaggle (Netflix Titles Dataset)  
- 8,807 rows · 12 columns

## 🛠️ Tools Used  
- Python (Pandas,Numpy)  
- Jupyter Notebook
- Power BI (Visualization)


## 🔎 Approach  
1. Removed unnecesary Coulmns - show_id & description.
2. Replaced missing values in country, date_added, rating, and duration columns with mode values of their coulmns.
3. Replaced missing values in cast, director column with the default value - "Not Mentioned".
4. Performed exploratory data analysis (EDA) to identify trends.  
5. Visualized distribution of content by genre, year, and country.

## 💡 Key Insights  
- Netflix has the highest content additions after 2015.  
- Most content belongs to Drama and Comedy genres.  
- USA and India dominate Netflix’s content library.
- TV shows make up the large majority of about 71% of the content.
- The content is Primarily geared towards mature audiences, with TV-Ma(mature) and TV-14 ratings being most common.
